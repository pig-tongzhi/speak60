# 即兴一分钟

单文件网页，训练一分钟即兴表达。不需要联网、不需要装任何东西。

## 直接用（推荐手机）

**https://pig-tongzhi.github.io/speak60/**

手机浏览器打开就能练，布局和触摸都已适配。想离线用就存成书签或添加到主屏幕。

## 用手机连电脑（局域网）

不想走公网就用这个，改完立刻生效，不用等部署：

```bash
./serve.sh          # 启动，会直接打印出手机该访问的地址
./serve.sh 8888     # 换端口
./serve.sh stop     # 停止
```

然后手机连**同一个 Wi-Fi**，打开脚本打印的地址（形如 `http://192.168.1.203:8080/`）。

- 只服务 `speak60` 这一个目录，上级文件取不到（`../` 一律 404，已实测）
- 电脑休眠或换网络后地址会变，重新跑一次 `./serve.sh` 即可
- 手机和电脑不在同一网段（比如手机用流量、或路由器开了 AP 隔离）会连不上，这种情况用上面的在线地址

## 本地用

1. 下载 `index.html`（右上角 Raw 右键另存，或 `git clone`）
2. 双击打开（推荐 Chrome / Edge / Safari）

文件名改成什么都行，`即兴一分钟.html` 也一样能用，不影响功能。

## 选题范围（设置里开关分类）

设置面板 →「题目分类」：8 个分类逐项开关，右上角「全选 / 全不选」一键切换。

- 底部实时显示「已开启 N / 8 个分类，共 M 题会被抽到」
- **抽题在所有开启分类的合集里等概率选取**，不是先随机分类再随机选题。因为各分类题量不等（47~80），先选分类会让小分类被过度放大
- 关掉当前正在选的分类，会自动落到第一个还开着的分类
- 至少保留一个分类：只剩一个时再点它不会静默无反应，而是给出「先开另一个」的提示
- 选择存在本地，下次打开还是这套

### 想只练某一块

比如只想练职场表达：关掉「日常杂谈」「身心状态」，留「一人公司与自由职业」「产品与创业」「AI 与智能体」，抽题池就变成这三类的合集。

## 时事（需要时可更新）

「时事」分类和其他分类不同——**它会过期**，所以没有写死在文件里，而是由一个脚本从 RSSHub 抓取生成：

```bash
node tools/gen-news.mjs        # 用本地 RSSHub
RSSHUB=http://127.0.0.1:1200 node tools/gen-news.mjs
node tools/gen-news.mjs --dry  # 只预览，不写文件
```

- 生成 `news-data.js`，页面刷新即可看到「时事」分类
- 需要 Node 18+（本机是 `~/.nvm/versions/node/v22.22.3/bin/node`）
- 默认源：财新、虎嗅、Readhub、果壳、少数派、36氪（在脚本顶部 `SOURCES` 里改）
- 设置面板里会显示抓取时间与来源，方便判断是否该重新生成

**脚本内置了过滤**，会挡掉三类不适合当演讲题目的内容：政治宣传口径、纯行情播报（涨跌/指数/财报）、明星八卦与营销号体。这些拿来练即兴表达既不好讲，也有发布风险。

**没有 `news-data.js` 时会自动降级**：应用不报错，「时事」分类直接不出现，其余 11 个分类正常工作。

## 外观（设置面板里切）

点右下角「设置」→ 顶部两组控件：

- **深浅**：深色 / 浅色。默认跟随系统，切过一次后记住你的选择
- **配色**：青蓝（默认）/ 暖琥珀 / 朱砂红 / 紫罗兰 / 薄荷绿

两点说明：

1. **浅色不是把深色反色。** 每套配色在浅色模式下会自动换成更深的同色系（比如青蓝 `#4aa8ff` → `#1d6fc4`），否则亮色压在白底上会发飘、按钮上的字也读不清。每个按钮文字色都按 WCAG AA（对比度 ≥4.5）算过。
2. **浏览器图标（favicon）会跟着变。** 图标是倒计时环 + 指针，颜色和底色都跟随当前主题与配色。内联 SVG，零外部文件。

`palette-preview.html` 是当初挑选配色用的对比页，5 套 × 深浅一次性并排渲染，留着方便以后换色参考。
线上地址：https://pig-tongzhi.github.io/speak60/palette-preview.html

## 两种模式

| 模式 | 练什么 |
|---|---|
| 临场直接讲 | 抽到就开口，不给准备时间，练临场组织语言 |
| 先查再讲 | 抽题后先给研究倒计时（默认 10 分钟），准备好再讲，练表达深度。研究中途可以「再加 5 分钟」 |

## 时间到的时候会发生什么

不是只换一行小字——正在讲话的人很容易看不见。归零那一刻会同时做四件事：

1. **整屏闪烁**：accent 色的光晕扫过整个屏幕三下，余光里也能察觉
2. **大字横幅**：倒计时圆环让位，居中显示「时间到」+ 本轮用时（比如「这轮一共 1 分 30 秒（含加时）」）
3. **声音 + 振动**：提示音，Android 上还有振动，并且**每 2.5 秒重复一次**，直到你处理它
4. **按钮变成明确的收尾动作**：主按钮由「提前结束」变成「讲完了」，次按钮变成「再讲 30 秒」

题目会一直留在屏幕上，不会因为时间到就消失，方便你看着收尾。

点「再讲 30 秒」会退回进行中状态：闪烁停止、重复振动停止、圆环和倒计时恢复、按钮回到「提前结束」。研究模式的归零同理，只是文案换成「研究时间到」并显示已查时长。

设置里勾了「静音提示音」时，提示音和振动都会关掉（重复提醒也不会触发）。

## 计时遮罩里的三段结构

倒计时期间屏幕上会依次高亮三个提示，对应一分钟的三个部分：

- **是什么？** — 先给结论或定义，别铺垫
- **所以呢？** — 为什么这件事重要，跟听众有什么关系
- **然后呢？** — 一个具体例子或行动建议，收住

提示是按已用时间自动推进的，跟着走就能把一分钟填满，不会讲到一半没话说。

## 怎么改题

用任意文本编辑器打开 `index.html`，搜 `var NICHES`，题库就在下面，格式一眼能看懂：

```js
{
  id: "ai-agent", label: "AI 与智能体", icon: I.robot,
  topics: [
    "大模型幻觉", "上下文窗口", "提示词工程",
    // 直接往下加就行
  ]
}
```

- **加题**：往对应 `topics` 数组里加字符串
- **删题**：删掉那一行
- **加一个新领域**：复制整个 `{ id, label, icon, topics: [...] }` 块粘在后面，改掉 `id`（英文，唯一）和 `label`。`icon` 从同文件顶部的 `var I = { ... }` 里挑一个现成的（如 `I.spark`、`I.robot`），领域下拉会自动多出一项，题数也会自动更新
- **改深度研究题库**：搜 `var RESEARCH`

改完存盘，刷新页面即可。不需要任何构建步骤。

## 声音

有声音，三处提示音：抽题定格、开始计时、时间到。用 Web Audio 现场合成正弦音，没有音频文件，设置里可关。

手机上要注意两点：

1. **iOS 的静音拨片会一起静音。** 这是 Safari 的行为——网页音频在「响铃/静音」拨到静音时不会出声。练的时候把拨片拨回响铃，或者就靠屏幕上的倒计时。
2. **第一次点击才会解锁音频。** iOS 要求音频必须在真实用户手势里激活。所以代码在每次点击「抽题 / 开始计时」时都主动解锁一次；并且在 `resume()` 完成前不会排程声音（这一步是必须的，否则 iOS 上第一次提示音会被静默丢掉——表现为「第一声不响」）。
3. **Android 上还有轻振动**（抽题 35ms、开始 25ms、结束三段）。iOS Safari 不支持振动 API，会静默忽略。

## 手机适配

已经在这些尺寸上逐个验证过（无横向溢出、按钮都在视口内、触摸目标 ≥44px）：

iPhone SE 320×568 · iPhone 8 375×667 · iPhone 12/13 390×844 · iPhone 14 Pro 393×852 · iPhone Plus 430×932 · Android 360×640 · Android 412×915 · **iPhone 横屏 844×390** · iPad mini 768×1024 · 桌面窄窗 500×700

几处专门处理过的地方：

- **横屏按「高度」而不是「宽度」切换布局。** 手机横屏宽度 844px 看着像大屏，但高度只有 390px。如果按宽度判断就会把倒计时圆环放大到 248px，把「讲完了」「加 30 秒」挤出屏幕点不到。现在改为 `min-height: 700px` 才放大，矮屏另有一套收紧的尺寸。
- **触摸目标全部 ≥44px**，包括领域菜单项和设置里的色板。
- **输入控件字号 ≥16px**，避免 iOS 聚焦时自动放大页面。
- **四边都留了安全区**（`env(safe-area-inset-top/right/bottom/left)`）。横屏时左右会有刘海/灵动岛，竖屏时顶部有状态栏、底部有 home 指示条。验证方式是注入一组模拟刘海（top 52 / right 59 / bottom 34 / left 59）后检查内边距确实跟随，而不只是「浏览器支持 `env()`」。
- 高度用 `100dvh`，地址栏收起/展开时不会跳动。
- 没有禁用缩放（不写 `user-scalable=no`）。

## 说明

- 所有设置（领域、模式、两个时长、静音、深浅、配色）存在浏览器 localStorage，换设备不同步
- 不联网、不上传、不收集任何数据
- 界面图标与浏览器图标全部是内联 SVG，没有用 emoji（emoji 在 Windows / Android 上渲染差异很大，会破坏视觉一致性）
- 字体只用系统字体，不加载任何 Web Font
- 换配色时浏览器图标同步更新：每套配色在 `PALETTES` 里同时登记 `swatch`（深色版）和 `swatchLight`（浅色版），这两个值必须和 CSS 里的 `--c` 保持一致
